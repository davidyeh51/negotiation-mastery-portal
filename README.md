## 一、無雜訊簡報三大核心原則（Zero-Noise Principles）與分級體系

1. **無雜訊簡報三大鐵律（`/zero-noise-pptx`）**
   - **形式必須對應邏輯（Form Follows Logic）**：徹底摒棄千篇一律的條列式排版，全 16 頁簡報依論證結構精準對應 **8 種無雜訊簡報版型（一對一、並列、結合、連鎖、麥肯錫、對立、比較、BCG 2×2 矩陣）**。
   - **由上而下的閱讀動線（Top-Down Reading Flow）**：每頁嚴格切分為「**① 上方主張（一句話核心結論）**」與「**② 下方證據（視覺圖表 Exhibit ＋ 結構化表格 Table）**」，讓聽眾 3 秒內完成結論與證據對齊。
   - **極致視覺降噪（3-Color Rule — 強調色只給唯一主角）**：單頁嚴格控制在 **3 種主色調以內**——麥肯錫深海藍主色（`#051C2C` / `#1E3A8A`）、冷灰階對照基準色（`#F8FAFC` / `#CBD5E1` / `#64748B`），唯獨「**核心突破點／唯一主角**」使用琥珀金強調色（`#D97706` / `#FEF3C7`）。

2. **入門至進階三階能力分級（Level 1 ➔ Level 3）× 整潔・精準・專業**
   - **Level 1｜入門基礎（Foundation）**：建立正確談判認知、區分表面訴求與真實需求（分橘子冰山模型）、破除「和氣＝雙贏」迷思、建立離桌底氣（Slide 01–05, 12）。
   - **Level 2｜進階實戰（Practitioner）**：掌握先後手報價 2×2 矩陣、報完價立刻閉嘴鐵律、遞減讓步、三級條款分類、假設性提問、五大心理戰反制與標準拒絕公式（Slide 06–09, 13–14）。
   - **Level 3｜高階破局（Executive Mastery）**：運用「價值鏈三角形」引入第三方做大增量利潤、A/B/C 三方案設計、精準擊破組織決策三角色（拍板人／評估人／執行人）與「談判前一頁紙」全局控盤（Slide 10–11, 15–16）。
